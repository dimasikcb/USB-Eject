USB-Eject — принудительное безопасное извлечение USB-дисков
============================================================

ПРОБЛЕМА
--------
Windows не даёт «безопасно извлечь» флешку/диск, потому что какой-то процесс
держит открытые файлы или сам том. Утилита находит таких «держателей»,
показывает, ЧТО именно мешает, даёт выбрать, что остановить, и выключает
устройство.

КАК ПОЛЬЗОВАТЬСЯ
----------------
1. Двойной клик по USB-Eject.bat (или по USB-Eject.ps1).
2. Если диск один — он выбирается сам. Если несколько — выбери цифру.
3. На вопрос «Извлечь диск ...?» нажми Y (или Enter), n — отмена.

Утилита:
  - сама находит всех, кто держит диск, и объясняет простыми словами:
      СЛУЖБА    — служба Windows (останавливать безопасно, потом запустится сама);
      ПРОГРАММА — программа открыла файлы с диска (несохранённое может пропасть);
      ПРОВОДНИК — окна диска и кэш миниатюр (закрывать безопасно);
      СИСТЕМА   — защищённый процесс Windows (не трогаем);
  - показывает вердикт: безопасно или осторожно;
  - после твоего «да» сама останавливает найденные программы и службы,
    закрывает окна Проводника, сбрасывает кэш, размонтирует том
    и выключает USB-устройство;
  - остановленные службы запускает обратно после успешного извлечения;
  - удаляет PnP-узлы устройства — Windows не показывает свои окна
    «устройство ещё используется» и диск не зависает при переподключении.

Дополнительные режимы (в PowerShell):
  powershell -File USB-Eject.ps1 -List       — список USB-дисков
  powershell -File USB-Eject.ps1 -Scan E     — кто держит диск E (ничего не меняет)
  powershell -File USB-Eject.ps1 -Kill E     — извлечь E без вопросов (авто-режим)
  powershell -File USB-Eject.ps1 -NoElevate  — запустить без запроса прав (просмотр)

Примечания:
  - USB-Eject.ps1 сам запрашивает права администратора при запуске (окно UAC).
  - Если Windows SmartScreen предупреждает — «Подробнее» -> «Выполнить в любом случае».
  - Остановка процессов принудительная: несохранённые данные в этих программах
    могут быть потеряны — это и есть цель (отпустить диск).
  - Если на диске файл подкачки или ReadyBoost — извлечение невозможно,
    пока эти функции не отключить (утилита предупредит).
